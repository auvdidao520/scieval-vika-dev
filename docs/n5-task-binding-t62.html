t62：任务创建后的绑定恢复

基于 t61 提交 cef9cb7。本阶段补充了恢复编排及故障测试，尚未完成生产可信网关和 Vika 调度器接线。

当前不可用于自动投递：新代码依赖一个尚不存在的可信网关，不能从测试替身推断真实 Vika、OpenViking 或 SciEval 已经联通。

处理流程

读取作业状态
必须 received→网关预留任务
按 job 幂等，不启动 worker→核对 job、原始事件序号、task→持久化 job → task→网关幂等激活任务

scieval-vika-p0/task_recovery.py:recover_task_binding 把预留和激活拆开，预留成功但状态写入失败时，不激活任务。重试必须找回同一任务；如果状态写入成功但激活结果未知，再次激活同一任务。保存的 task 与预留结果不一致时抛出冲突，不覆盖。

失败和恢复

故障位置处理测试覆盖
任务已预留，OV 绑定写入失败不激活；重试复用预留任务替身注入 RuntimeError('write failed')
绑定已写入，激活请求结果未知重试核对同一 task 后激活替身注入 TimeoutError('activation outcome unknown')
job 或原始序号不一致拒绝绑定和激活有
已有不同 task 绑定拒绝覆盖和激活有

这些异常是测试主动注入，不是真实服务报错。第一次执行命令时工作目录写错，提示 No such file or directory 且环境没有 python；修正相对路径并使用 python3 后通过。

验证结果和边界

在 scieval-vika-p0 目录运行 python3 -m unittest discover -s tests -v：36 次测试执行通过，其中部分由继承测试类重复执行。网关和 OV 使用内存替身，未覆盖跨进程崩溃、真实服务认证、持久化并发或 Vika worker 启动。

  2. 实现受限可信网关与服务间身份认证、指定 SciEval connector 实例和报告摘要校验，连接 Core 账本与 TaskManager；禁止外部或模型伪造事件。
