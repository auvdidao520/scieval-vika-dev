教案 HTML 修订稿交回 SciEval 复评

阶段结果 · 基于 PR #27 · 2026-11-13

循环与交付

教师提出意见，SciEval 按教学指标评估教案，Vika 派工修改 HTML 幻灯片，修订稿返回 SciEval 使用同一指标复评。未达标项应带着证据回到 Worker，再次复评；通过后交教师确认。

已增加显式交接入口 review_worker.py：提交修订 HTML 的实际内容，检查任务关联、作业轮次、文件摘要和量表版本，返回 13 项评分、原文证据、建议与逐项通过或需修改结果。未评分项进入人工复核。

尚未打通

这仍是试点，可信宿主必须手动提供 Worker 输出、任务 ID 和轮次。尚未接入 Worker 完成事件、自动回派和限轮、渲染评测、教师确认或发布。原生 task_route 接收已认证的输入事件，需要先确定可信交接方式，不能把评测报告伪装成输入事件。

量表评分锚点、模型和通过阈值均未校准，结果只作为建议，最终状态固定为人工复核。文本匹配不能证明教学判断或定位正确。

验证

10 项 Python 测试通过，含本地模拟模型的修订 HTML 上传、报告证据、需修改与通过建议、幂等重试以及错误报告拒绝。未验证真实模型和真实 Vika 服务的端到端流程。
