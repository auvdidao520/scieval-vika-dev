已有接口

反馈分类

POST /v1/feedback/classifications，Bearer 认证；每次调用模型，无幂等缓存。

{
  "schema_version": "1.0", "job_id": "lesson-1", "round": 1,
  "rubric": {"id":"scieval-equip-13", "version":"draft-1"},
  "policy_version":"draft-1", "feedback":"实验步骤有误",
  "artifact": {"uri":"lesson.html", "media_type":"text/html",
    "sha256":"<内容 SHA-256>", "content_base64":"<UTF-8 HTML>"}
}

输出 issues[]，每项含指标、教师原话、HTML 原文、置信度与验收条件；status 为 needs_clarification 或 human_review，不会直接批准派工。

修订稿文本评测

POST /v1/evaluations 接受相同材料字段，需 Idempotency-Key；返回评测 ID。GET /v1/evaluations/{id} 返回报告。

{
  "status": "succeeded",
  "report": {
    "input_sha256": "<修订稿 SHA-256>",
    "criteria": ["13 项评分与原文证据"],
    "decision": {"result":"human_review"}
  }
}

示例为结构示意，criteria 实际为对象数组。当前评测只发送 HTML 文本，不读取截图，也不对比教师反馈验收条件。

错误与重试

情况接口行为调用方处理
认证失败401检查凭据，不派工
字段、版本或摘要不符400，超大请求 413修正输入，重新提交
模型不可用或证据无效502人工或调用方重试；分类每次调用模型
评测幂等键冲突409同一键只能对应同一请求；版本变更使用新键
证据缺失、低置信度needs_clarification；门槛 0.7 为未经校准的试点值补充教案位置或教师说明，不自动派工
