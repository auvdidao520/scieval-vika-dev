从文件到报告

按实际执行顺序排列。选中节点后，下方显示代码位置和该步骤的输入、输出、失败分支。

两个接口

POST /v1/evaluations

Bearer token 认证；Idempotency-Key 是调用方稳定键。服务同步调用模型，成功返回 200。

{
  "schema_version": "1.0",
  "job_id": "lesson-001", "round": 1,
  "artifact": {
    "uri": "lesson.html", "sha256": "…",
    "media_type": "text/html",
    "content_base64": "…"
  },
  "rubric": {"id":"scieval-equip-13", "version":"draft-1"},
  "policy_version": "draft-1"
}

返回 {"evaluation_id":"…", "status":"succeeded"}。重复同键同请求返回相同 ID；同键不同请求返回 409。

GET /v1/evaluations/{id}

同样需要 Bearer token。已完成的结果以内联报告返回；未知 ID 返回 404。

{
  "status": "succeeded",
  "report": {
    "evaluation_id": "…", "job_id": "lesson-001",
    "round": 1, "input_sha256": "…",
    "rubric_id": "scieval-equip-13",
    "rubric_version": "draft-1",
    "criteria": [ /* 恰好 13 项 */ ],
    "decision": {"result": "human_review", "reason": "…"}
  }
}

示例为字段展示，实际报告还包含输入 URI、策略、评测器版本及创建时间。

每一项评分带什么

字段检查和含义
criterion_id13 个指定 ID 各一次，缺项或重复均拒绝。
status / scorescored 为 0–3 整数；not_observable 或 error 的分数必须为 null。scored 必须有证据。
evidence[]每项提供 quote 和 locator。服务检查 quote 是否出现在原始 HTML，附输入摘要；不会验证 locator 是否正确。
reasoning / recommendations模型解释及建议，供教师审阅，不作为执行指令。
decision当前恒为 human_review。不能将模型分数理解为已批准发布。

维度包含现象/解决方案、科学与工程实践、学科核心概念、跨学科概念、三维整合、相关性、学生想法、科学准确性，以及五项评估与学习机会。完整 ID 见 framework.py:12。

失败时发生什么

触发结果下一步
缺少或错误 token401检查本地 token 文件。
请求格式、HTML 编码、摘要或版本无效400；请求过大 413检查输入与摘要后重新提交。
同一幂等键对应不同请求409检查作业、轮次与键；不要覆盖旧报告。
模型不可用、格式不符或引用不存在502，失败不存报告排查模型服务，用同一键重试。
模型已完成，服务在保存前崩溃可能重复模型调用重试同一键；需接受潜在重复费用。

服务单线程且仅监听本机；同一个数据库只运行一个实例。SQLite 只保存接口幂等结果与报告，不承担任务调度。

怎么试与当前验证

运行

准备本地 token 和模型密钥，启动服务后，用 CLI 指定 HTML、job ID、轮次及输出文件。完整命令见 运行说明。

python3 scieval-evaluator/evaluate.py lesson.html \
  --token-file /安全目录/local-token \
  --job-id lesson-001 --round 1 --output report.json

验证范围

本地模拟模型测试覆盖 HTTP 提交与查询、重复提交、13 项报告、拒绝伪造引用，以及已有客户端的跨域和摘要校验。没有真实模型质量测试，也没有接通 Vika 的 Worker 改稿、审批或发布。

接口发送完整 HTML 到配置的模型端点，使用前需确认该服务可处理材料。
