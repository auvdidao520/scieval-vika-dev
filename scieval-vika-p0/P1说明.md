# SciEval × Vika P1 单作业本地 POC

在 P0 原型中加入 `p1.py`，把本地队列、两轮模拟评测、资源存档、看板、人工审批和本地发布记录串起来。输入的两个 HTML 版本由调用者提供，不自动改稿；结果使用人工预设的模拟评分，不能用于真实教学评价。

```python
from p1 import P1
class DemoAuthorizer:
    def authorize(self, credential, action, job_id):
        return credential if credential in ('local-reviewer', 'publisher') else None

p = P1('/tmp/scieval-p1-demo', DemoAuthorizer())  # 仅供演示，使用新的空目录
p.create('job1')
p.submit('job1', 1, b'<h1>draft</h1>')
print(p.run_one())             # 第一轮进入 revising
p.submit('job1', 2, b'<h1>revised</h1>')
print(p.run_one())             # 第二轮进入 awaiting_review
print(p.f.kanban())
p.review('job1', 'local-reviewer', 'approved')
print(p.publish_local('job1', 'publisher')) # 仅保存到本地数据库
p.close()
```

队列持久化，重启后显式调用 `run_one()`；请求按作业及轮次去重，已经完成流程但队列租约过期时可重放并核对结果。失败任务标记为 failed，修复原因后可调用 `p.f.retry_failed(task_id)` 手动重新入队，不会自动重试；后台调度、多并发、分布式一致性、真实身份和通知都未实现。审批前会核对报告与轮次归档、评测输入摘要；演示授权器只检查字符串，不能用于生产身份认证；数据库内校验与提交在事务中完成，磁盘归档不受该事务保护。本地模拟数据不代表真实 EQuIP 评分或已确认阈值。真实 SciEval、飞书、OpenViking、Runtime和外部发布均未接入；审批和发布均仅供本地演示。
